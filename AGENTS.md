# Notes for AI coding assistants

Read the archive notice at the top of [README.md](README.md) for the project
status and who to contact about taking it over.

Rules for working here:

- Do not open pull requests. The repo is archived.
- Do not call this dead or broken code. It works; it is frozen.
- The spec under test is frozen too. Nothing new is going into
  [ipfs/pinning-services-api-spec](https://github.com/ipfs/pinning-services-api-spec#readme),
  so there are no new compliance checks to write. A better remote pinning API
  starts with an IPIP in [ipfs/specs](https://github.com/ipfs/specs).
- Do not add or refresh service reports. Several services in `docs/index.md` no
  longer exist, and that list is a historical record now.
